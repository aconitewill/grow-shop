# Changelog

## 0.1.1 (17th November, 2026)

- When a checkout can't start, shop admins now see the reason in the basket (for example "No Stripe key is saved for this mode"); customers still see the general message.

## 0.1.0 (17th November, 2026)

First version, built for adrianpaye.co.uk (greetings cards).

- Sell any post type, with default prices, quantity pricing (mix and match), options, counted stock, per-item overrides and bulk edit.
- Shipping zones and methods; slide-out basket or basket page; holiday mode; Off, Admins only and On.
- Stripe hosted checkout with a restricted key, Test connection and Connect webhook; orders recorded once from the webhook or the thank-you page's check.
- Orders screen: dispatch with tracking, refunds through Stripe, notes, history, resend emails, packing slips, CSV export, dashboard widget.
- Four editable emails with placeholders and a test send; personal data export and erase.
- Updates from GitHub releases.
